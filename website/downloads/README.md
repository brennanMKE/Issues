# downloads/

Release DMGs are published here as `Issues-<X.Y.Z>.dmg` and referenced by the
Sparkle appcast (`../appcast.xml`) enclosure URLs:
`https://issues.sstools.co/downloads/Issues-<X.Y.Z>.dmg`.

Copy the notarized DMG produced by `scripts/release.sh` here (renamed to the
marketing version) before running `scripts/deploy-website.sh`. See
`scripts/RELEASE.md` step 6.
